# World Weather Dashboard

This project collects weather data from cities around the world using Selenium.

The data is cleaned with Pandas, saved to SQLite, and displayed in an interactive Streamlit dashboard.

## Features

- Temperature range filter
- Top 10 hottest cities
- Temperature distribution
- Most common weather conditions
- Filtered weather data table
